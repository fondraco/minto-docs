Sending organizations are the schools and agencies abroad that send you
students. Linking one lets you set it on internships and, when it has its own
Minto account, lets both sides work from the same records.

There are two ways in, depending on whether they already use Minto.

<Columns cols={2}>
  <Card title="Connect" icon="link">
    They already use Minto. You exchange a code and both organizations are
    linked to each other.
  </Card>
  <Card title="Create" icon="file-plus">
    They don't use Minto yet. You create a placeholder to work with in the
    meantime.
  </Card>
</Columns>

## Before you begin

- Any role can connect an organization.
- To connect, you need the organization's **6-character code**. They'll find it
  in their own Minto organization settings and send it to you.

## Connect an organization that uses Minto

<Steps>
  <Step title="Open the organizations list">
    In the sidebar, select **Organizations**.
  </Step>
  <Step title="Start connecting">
    Select **Connect**.
  </Step>
  <Step title="Enter their code">
    Enter the 6-character code they gave you, then select **Connect**.
  </Step>
</Steps>

The organization appears under **Sending Organizations** and can be chosen when
you create an internship.

## Create a placeholder instead

Use this when the school hasn't registered with Minto. It behaves like a real
sending organization for planning purposes — you can link it to internships and
replace it later when they do register.

<Steps>
  <Step title="Open the organizations list">
    In the sidebar, select **Organizations**.
  </Step>
  <Step title="Start creating">
    Select **Create**.
  </Step>
  <Step title="Name it">
    In **Name**, enter the school or agency's name, then select **Create**.
  </Step>
</Steps>

## Result

The organization appears in your list. Filter with the **Sending Organizations**
tab if the list is long.

## Troubleshooting

**The code isn't accepted.**
Minto tells you which of three things went wrong: *"No organization found with
this code."*, *"Already connected to this organization."*, or *"Cannot connect
to your own organization."* The first usually means a mistyped character — the
field takes exactly six and won't submit until it has them.

A branch code works here too, not just the organization's own code.

**You created a placeholder and now they've registered.**
Connect the real organization with their code, then move the internships across
and remove the placeholder. Don't leave both — you'll end up recording the same
partner twice.
